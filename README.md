# Thasneem Mohamed - Developer Portfolio

An interactive, highly-designed developer portfolio built with Next.js, Tailwind CSS, and Framer Motion. 

## 🚀 Features
* **Interactive Hacker Grid:** A custom background element that reacts to mouse movement and reveals skills on hover.
* **Visual System Design:** Project pages feature interactive architecture diagrams (React Flow) explaining the tech stack, environments, and engineering decisions.
* **Responsive Dark Theme:** Built with a sleek, modern dark aesthetic.

## 🛠️ Tech Stack
* Next.js (App Router)
* React
* Tailwind CSS
* Framer Motion
* React Flow
